# The hard school: tests where keeping text and looking it up should struggle (plan and pass rules)

*Written 2 Nov 2026, committed 03:50 IST (c84e1dd) on branch `brain-v5`, before any of these tests ran (not even a smoke). The rules and
predictions don't change after results are seen. Code: `brain/hardschool.py`. The student is v5, unchanged: the
childhoods and the chosen layers of [V5.md](V5.md) (135M layer 4, the main verdict; 1.7B layer 13, reported).*

## Why

v5 passed all its rules ([V5.md](V5.md)), but RAG tied or beat it on most rows. V5.md's rule for "all pass" says
the next step is tests where keeping text and looking it up struggles. Two of the three it names are built here:

- **A. Facts that change many times.** RAG ranks stored sentences by how much they look like the question, not by
  how new they are. When a fact changes in other words ("Zubak moved to Kelm"), the old sentence can still look
  more like the question ("Zubak lives in a town called"), and RAG reads the old fact. v5's delta rule writes the
  new value over the old one at a nearby address.
- **B. Many facts in one sentence.** One sentence carries all five of a person's facts. RAG finds the sentence
  easily, but the LLM must pick the right name out of five in it. v5 must keep five facts apart that share one
  sentence's address.
- **C. Combining facts without a fixed plan** is not built here. V5's school already asks it ("two-step asked
  directly"): v5, RAG and the LLM with no memory are all at chance (24–31%). It needs a new idea (a second read
  inside the memory), so it is a later version, not a test of this one.

## The tests

Both use the school's world (`brain/school.py`): 40 people, 5 facts each (pet, town, best friend, toy, secret
word), dev names with world seed 0, test names with seed 1. A lesson is one session: the fact sentence inside a
story. An ordinary story follows each lesson. There is no quiz and no correction: the exam comes right after the
last lesson. A fact counts as known when the right name has the highest likelihood of 5 names.

**A. Changes.** Every fact is taught once (one of the school's 3 lesson wordings). Then each person's town and toy
change 3 times, in 3 rounds; each change is taught once, in a change wording:
- town: "{s} moved to {o}.", "{s} now lives in {o}.", "These days {s}'s home is {o}."
- toy: "{s} got a new toy, {o}.", "Now {s} plays with {o}.", "{s}'s new favourite toy is {o}."
Change k of a fact uses change wording k. Rounds come in order; within a round the order is random.
- Exam: the current town and toy (80 facts), asked the plain way (the school's `ASK`) and in other words (the
  school's exam wording). **The 5 names are the current one, the 3 older ones and 1 other.** So reading an old
  value is a wrong answer.
- Also reported: the three facts that never changed (pet, friend, secret; 120), asked the plain way.

**B. One sentence, five facts.** Each person's five facts are taught once in one sentence, one of three orders:
- "{s} lives in {town}, has a {p} called {pet}, plays with a toy named {toy}, keeps the secret word {secret} and
  likes {friend} best of all."
- "{s} has a {p} called {pet}, likes {friend} best of all, lives in {town}, keeps the secret word {secret} and
  plays with a toy named {toy}."
- "{s} keeps the secret word {secret}, plays with a toy named {toy}, likes {friend} best of all, has a {p} called
  {pet} and lives in {town}."
- Exam: all 200 facts, plain and in other words (the school's `ASK` and exam wordings). **The 5 names are the right
  one, 2 of the same person's other names (from that sentence) and 2 others.**

## The learners (the same frozen LLM for each)

- **v5**, as in V5.md.
- **RAG-1**, V5's RAG: the one stored sentence that best matches the question's rare words (a tie goes to the most
  recent), put before the question. Here it has no 150-byte cut (that was for GPT's short context; a sentence in
  test B is up to about 190 bytes).
- **RAG-3**, a stronger RAG: the 3 best-matching sentences, put before the question **in the order they were
  read**, so the newest is last.
- **No learning.**

## Pass rules (test names, 135M, layer 4)

| Rule | Passes when |
|---|---|
| D1 changes: v5 knows the current value | plain + other words together (160 questions) ≥ 70% |
| **D2 changes: v5 beats RAG** | on those 160, v5 minus the better of RAG-1 and RAG-3: 95% bootstrap lower bound > 0 |
| D3 changes: the facts that never changed are kept | plain ≥ 85% |
| D4 one sentence: v5 knows the facts | plain ≥ 80% and other words ≥ 60% |

D2 is the headline: the first test where v5 is claimed to do better than RAG. Reported, not rules: everything
against RAG in B, each of plain and other words alone, the 1.7B numbers, dev numbers.

The bootstrap is `brain/lifetest.py`'s `bootstrap_lower` (paired by question), with 10,000 resamples.

## Predictions (written before any run)

- **A, changes.** v5 knows the current value about 55–75% of the time. Each change is written at the change
  wording's address, which is near the question's but not the same, so some of the old value is left. RAG-1 reads a
  stale sentence about half the time: 35–55%. RAG-3 sees old and new together; a 135M LLM picks the last one only
  sometimes: 40–60%. **D2 is a coin flip, perhaps 50%.** D1 passes a bit more likely than not. D3 passes (about
  95%).
- **B, one sentence.** v5 is weaker here than in V5's school: the who part of the address picks up the other new
  names in the sentence, so a question about the toy shares less of its address with the lesson. Plain 65–85%,
  other words 50–75%. **D4 more likely fails than passes.** RAG finds the sentence every time; RAG wins B, 80–95%.

## What happens next (fixed now)

- **D2 passes:** the first honest case where Shishya's memory beats keeping text and looking it up. Run it at 1.7B
  (Kaggle) and with more changes (5, 10). Then the product: a memory that keeps the latest of what it was told.
- **D2 fails:** v5's memory is not yet better than RAG anywhere tested. Its worth is then what RAG lacks by
  design (a fixed-size memory, no store of text, learning inside the model's read path), not accuracy. The next
  research step is the second read (test C) and sleep.
- **D4 fails:** the who part of the address must stop counting the other new names in the sentence (for example,
  only the sentence's first new name, or names bound to their role). That is a v6 change with its own dev run.

| D2 changes: v5 minus the better RAG (RAG-3), lower bound | > 0 | −37 points (v5 19%, RAG-3 47.5%) | fail |

| B. One sentence, other words | 34.5% | 47.5% | **61%** | 23.5% |

(Chance is 20%. In A the wrong choices are the fact's own older values, so a learner that reads an old value
scores below chance: the LLM with no memory has none of them and gets 26%.)

**What went wrong, plainly.**
- **Changes don't overwrite.** A diagnostic on dev names (run after the results, changes nothing): asked the 80
  current values twice, v5 picked the current value 37 times, the original 38, the first change 29 and the second
  change 55. Each change is said in other words ("Zubak moved to Kelm"), so it is written at its own "what"
  address, not over the old one. The question then reads a blend of all four, led by whichever wording is closest
  to it. That is RAG-1's weakness (likeness, not newness), and v5 has no way to see the order, which is what helps
  RAG-3.
- **Changes also hurt the facts that didn't change.** Without changes (V5's school, before the quiz) plain recall
  was 96%. With 240 change lessons it is 72.5%: they share the person's "who" units, and the writes spill into the
  person's other facts. RAG keeps every sentence; its lower number here (48–64%) is probably the change sentences
  outranking the old fact's sentence in retrieval (not checked).
- **Five facts in one sentence share one address.** The "who" part counts every new name read so far, so by the
  toy the address holds the person, their town and their pet. A question about the toy names only the person.
  v5 falls from 96% (one fact per sentence) to 35.5%. RAG finds the sentence but the 135M LLM often picks the
  wrong name from it (54.5–68.5%).

**Predictions vs results.** I predicted D2 a coin flip, D1 likely to pass, D3 to pass and D4 likely to fail. All four
failed, and by far more than I guessed (A: 19% against my 55–75%; B: 35% against 65–85%).

**What happens next (as fixed above).**
- D2 failed: **v5's memory is not better than RAG anywhere tested.** What it has that RAG lacks is by design: a
  fixed-size memory, no store of text, and learning inside the model's read path. The research steps are the
  second read (test C) and sleep.
- D4 failed: the "who" part must stop counting the other new names in the sentence (for example, only the
  sentence's first new name, or names bound to their role). That is a v6 change, with its own dev run.
- Learned from A, for v6: an update must land where the old fact is. Two ways: write the change at the address
  the question will use (the "what" learned in childhood from many update wordings, so "moved to" and "lives in"
  meet), or erase along the person's "who" units for that kind of fact before writing. Both need a new childhood
  with changing facts in it.
