# Shishya v7: a reader that knows what a sentence is about, plus sleep (plan and pass rules)

*Started 2 Nov 2026, 17:30 IST. Code: `brain/v7.py`. Why sleep, and the research behind it:
[ROADMAP_V7.md](ROADMAP_V7.md).*

## The design (no gradients, awake or asleep)

- **Awake:** v5/v6's local delta rule. Each write also leaves a trace: who units, what vector, the token written,
  its strength. Traces are numbers, not text. A write that starts a new name begins a "fact".
- **Reconsolidation (awake):** before a new name is written, Shishya recalls what its memory holds at that address.
  If it recalls the start of a different live name at a close address, that old fact is replaced: marked dead and
  erased at once.
- **Sleep (every "day"):** the memory is rebuilt from zero out of the live traces, in 3 shuffled passes of the same
  rule (interleaved replay). Dead facts are gone for good.

## Dev notes (dev names only; not results)

**First try, on v5's reader (SmolLM2-135M, layer 4), hard school A:**

| Mode | Current value, plain + other words | Never-changed facts | Facts replaced |
|---|---:|---:|---:|
| v5 as is (V6.md) | 23% | 66% | |
| Reconsolidation only | 22% | 60% | 56 of 240 changes |
| Sleep only (8 sleeps) | 21% | 68% | |
| Both | 24% | 54% | 55 |

No effect. Erasing old values doesn't help, because the question's address can't find the new value: "Zubak moved
to Kelm" is stored at a meaning far from "Zubak lives in a town called". That is the read side, which v6's
childhood trains (W learns to put "moved to" where "lives in" is asked). So v7 is tried next on v6's reader.

**Second try, on v6's Brain reader (who = first name), hard school A, dev names:**

| Mode | Current value | Never-changed facts | Facts replaced |
|---|---:|---:|---:|
| v6 as is | 46% | 61% | |
| Reconsolidation (match 0.3 / 0.6) | 60% / 59% | 35% / 35% | 253 / 247 |
| Sleep, 8 times | 31% | 86% | |
| Both | 38% | 57% | 159 |
| Sleep, the later fact wins (resolve 0.5 / 0.7 / 0.85) | 52% / 56% / 53% | 25% / 25% / 32% | 317 / 301 / 280 |
| One sentence, five facts: clause meaning 0 / 0.5 / 1 (plain) | 32% / 32.5% / 33.5% | | |

- Sleep alone repairs what later writes damage (never-changed facts 61% → 86%), but it brings back old values.
- Every way of replacing old values also kills a person's other facts, even at a strict threshold.
- **The cause, measured.** For v6's reader, "has a dog named", "plays with a toy named" and "has a teacher named"
  have the same meaning (cosine 0.98–0.99), and so do "moved to" and "changed teacher to". The meaning is the
  last word. With the person's units shared, all of a person's "named" facts compete for one slot.
- **The Brain itself doesn't know it either.** A probe (5 kinds of fact, 3–5 wordings each, 3 names): for each
  phrase, is its nearest other-wording phrase about the same kind of fact? Chance is 20%.

  | Reader | Best layer and pooling | Same kind found |
  |---|---|---:|
  | Our Brain, 12.8M, TinyStories | layer 2, recent words weighted | 45% |
  | Pathway's BDH, 100M, FineWeb-Edu + TinyStories (free, MIT) | layer 3 or 4, mean over the phrase | 77% |
  | SmolLM2-135M (an LLM, for reference) | layer 27, last token | 85% |

  So no rule written on top of the 12.8M Brain can keep a person's facts apart. The 100M BDH, still with no LLM
  inside, is close to a same-size LLM.

## v7: the plan (2 Nov 2026, 23:30 IST, before any v7 childhood, dev or test result)

**What changes from v6.**
1. **The reader:** Pathway's 100M byte-level BDH ([d3vmeh/bdh-100m-bytes](https://huggingface.co/d3vmeh/bdh-100m-bytes),
   MIT, SHA-256 checked at load), frozen. It was moved here from v9, because v7's dev notes show the small Brain
   is the limit. Still no LLM inside: a BDH, like our Brain, eight times larger and trained on general English.
2. **The clause meaning** (`Reader.pool`, `v5.pool_states`): the "what" reads two things side by side, the step's
   own state and the mean of its clause's states so far, leaving out names. A clause ends at ". ! ?" and at ", " or
   " and " before a small letter. So "has a dog named" carries "dog", and the five parts of one long sentence each
   get their own meaning.
3. **The who:** the first new name of the sentence (v6's choice), so a person's facts share units and the
   meaning tells them apart.
4. **Sleep** (as above), chosen on dev from: none, sleep, sleep where the later fact wins at 0.8 or 0.9.

Life stays gradient-free (the local delta rule; sleep is the same rule replayed). Childhood (gradients, once)
trains only W (now 1,024 × 32), the rate and the gain: v6's episodes, who = first, 500 steps.

**Dev choices (dev names only), fixed now.**
- Layer 3 or 4: v6's dev score (`v6.dev_score`, the mean of five dev numbers); a tie goes to layer 3.
- Then sleep: `v7.choose_sleep`, the best mean of current value and never-changed facts on hard school A (dev
  names); a tie goes to the earlier of none, sleep, sleep 0.8, sleep 0.9.

**Pass rules (test names; the chosen reader and sleep).** The same bars as v6, so the two compare directly.

| Rule | Passes when |
|---|---|
| Y1 hard school A: the current value, plain + other words | ≥ 70% |
| Y2 hard school A: facts that never changed, plain | ≥ 85% |
| Y3 hard school B (one sentence): plain / other words | ≥ 80% / ≥ 60% |
| Y4 no step back: V5's rules V1–V5 on its school and life test | all pass |
| Y5 long life, final exam: never-changed plain / changed facts' current value / all facts in other words / bits per byte rise | ≥ 80% / ≥ 70% / ≥ 60% / ≤ 5% |

Overall pass: all five.

Reported, not rules:
- v6's Brain on the same tests (V6.md);
- SmolLM2-135M + RAG-3 on hard school A and B (V6.md);
- the examiner's wordings;
- the long life with no sleep;
- efficiency: parameters, memory rows used (bytes per fact), ms per session, GPU or not.

**Predictions (before any run).**
- Y4 passes; other words may rise (a reader of general English).
- Y2: 75–90%, a coin flip. Sleep should help; sharing the person's units still costs.
- Y1: 55–75%, a coin flip. Better meaning lets "moved to" land where "lives in" is asked.
- Y3: plain 50–75%, likely fails; better than v6's 34%.
- Y5 passes, as v6's did.
- **Overall: more likely FAIL than pass**, most likely on Y3, maybe Y1 or Y2. The size of the gain over v6 on
  Y1–Y3 is the real question: if the reader was the limit, all three should rise together.

**What happens next (fixed now).**
- All pass: v8 (thinking out loud) on this reader, then v9's test (the student beats its teacher, ROADMAP_V7.md).
- Y1–Y3 rise a lot but fail: the reader was the limit; train a reader on teacher-written text (the roadmap's
  "skills through the weights") before v8.
- Y1–Y3 don't rise: the memory itself is the limit (one slot per person and meaning). v8 then gives each kind of
  fact its own slot (roles), learned in childhood.

**Smoke checks (after this plan; not results).**

- A Kaggle canary (`shishya-brain-canary7`: 6 childhood steps, then the dev choices and hard school B on test

- The canary ran cleanly end to end in 86 minutes: about 22 s per childhood step, 2 min per dev check. So the

## v7: the results (3 Nov 2026, 05:50 IST; test names, run `shishya-brain-v7`)

(dev names), current value / never-changed:

|---|---:|---:|---:|

| sleep | 26.3% | 85.8% | 0.560 |

So the long life ran with no sleep, and the planned "long life with no sleep" report is the long life itself.

**Reported, not rules.**
- The examiner's wordings: school 67.5% (v6 70.5%), long life final 62.7% (v6 61%, RAG-3 72%). The larger
  reader of general English did not help with wordings the memory never saw.
- Long life, day by day (plain): 85, 91.5, 95.5, 86, 87.3%. Changed facts current: 86% on day 3 (after the quiz
  and 18 corrections), 72.5% after day 4's second wave, 74.2% at the end.
- Efficiency: a frozen 100M reader (no LLM: a BDH trained on general English), plus a trained W of 1,024 × 32,
  a rate and a gain. The memory is a fixed 268 MB; the long life used 11,541 of its rows. The write traces kept
  for sleep take 4.3 MB for 18,524 writes. 231 ms per session (median, Kaggle T4; v6: 333 ms).
- The run took 356 minutes on Kaggle's free GPUs: childhoods 213, dev 39, sleep dev 37, tests 67.

**Against the predictions.** Y4 and Y5 passed, as predicted. Y2 at 77.5% was inside the predicted 75–90%. Y1 at
46% was below the predicted 55–75%, and Y3 at 39% was below the predicted 50–75%. Overall FAIL, as predicted, but
on all three hard rules, not one.

**What it means.**
- **The reader was not the main limit.** The 100M BDH tells relations apart far better than the Brain (77% against
  45% on the probe), yet changes did not rise (they fell 4 points) and the one-sentence school rose only 5 points.
  Only never-changed facts rose clearly (+12.5 points), because the clause meaning keeps a person's facts further
  apart.
- **Sleep, as built, trades the new value for the old.** Replaying every live trace keeps never-changed facts
  (86% on dev) but brings old values back, because a change is only "dead" when the erase step finds it. Letting
  the later fact win helps the current value but costs the kept facts. On the mean, no sleep wins.
- **The long life still works and is better than v6's on what it keeps** (88% never-changed against 83%), and it
  beats RAG-3 by 41 points on changed facts, at 231 ms a session with no LLM inside.

**What follows (fixed in the plan above).** Y1–Y3 don't rise together (Y1 fell; Y3's gain is inside the noise),
so the "don't rise" branch applies: the memory itself is the limit (one slot per person and meaning). **v8 gives
each kind of fact its own slot (roles), learned in childhood,** on this reader (layer 3, clause meaning). A change
then overwrites only its role's slot, and five facts in one sentence go to five slots. The plan and pass rules
for v8 go in docs/V8.md before any v8 run. Sleep is parked until roles can say which trace a change replaces.
